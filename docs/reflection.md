# Reflection: GitHub and Project Planning

## What I learned
This lab taught me the fundamentals of version control using Git and GitHub.
I learned how to create branches and make meaningful commits and even merge changes via pull requests — even when working solo.
I also understood how GitHub Issues can function as a lightweight project management tool, similar to Trello or Jira.

## Challenges and interesting parts
The most interesting part was visualizing how teams can work in parallel using branches without interfering with each other's code. The most challenging part was remembering to write clear, descriptive commit messages instead of vague ones like "updated stuff". I also learned the difference between merging branches directly and using pull requests.

## Improvements if I had more time
With more time, I would:
- Deploy the dashboard using GitHub Pages so it's live
- Add actual Chart.js visualizations instead of placeholders
- Implement user authentication so students can log in and track their personal points

## Final thought
I realized that GitHub is not just for coding, it's a powerful collaboration and project management platform. I will definitely use issues, branches, and pull requests in my future group projects.
