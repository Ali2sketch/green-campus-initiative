# Green Campus Initiative 🌱

## Project Idea
Our campus produces significant paper and energy waste. This project tracks and visualizes campus sustainability metrics, encouraging students and staff to adopt greener habits.

**How it helps create a greener campus:**
- Tracks paper usage reduction goals
- Monitors energy consumption trends
- Rewards eco-friendly behavior via a simple point system

## Technologies Used
- HTML/CSS (frontend dashboard)
- JavaScript (interactivity)
- Google Sheets (data storage - no database needed)
- GitHub Pages (hosting)
